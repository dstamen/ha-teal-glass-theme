# Teal Glass Theme

A dark-navy / light-mint Home Assistant theme with teal (`#2dd4bf`) and cyan (`#38bdf8`) accents, built to match a glass-card dashboard aesthetic. Automatically follows the app's light/dark mode setting via native `modes:` support.

## Install via HACS

1. HACS → the `⋮` menu (top right) → **Custom repositories**
2. Repository: this repo's URL, Category: **Theme**
3. Install "Teal Glass Theme"
4. Settings → Appearance (or your user profile) → Theme → **teal_glass**

## Colors

| Token | Dark | Light |
|---|---|---|
| Primary accent | `#2dd4bf` (teal) | `#0d9488` (deep teal) |
| Secondary accent | `#38bdf8` (sky) | `#0284c7` (deep sky) |
| Background | `#0a0e1a` | `#f4f7f6` |
| Card | `rgba(24,31,53,0.92)` | `rgba(255,255,255,0.97)` |
